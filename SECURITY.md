# Source Switcher security policy

## Supported version

Use the latest Windows x64 build from [Source Switcher Releases](https://github.com/EnzoChizari/source-switcher/releases) when checking whether a vulnerability still reproduces.

## Report a vulnerability

If GitHub offers **Report a vulnerability** on the [repository's Security tab](https://github.com/EnzoChizari/source-switcher/security), use it to submit a private report. If that option is unavailable, contact the maintainer through a private channel you already have and ask where to send the report securely. Keep vulnerability details out of public issues and pull requests.

Include the app and Windows versions, the steps to reproduce, the impact, and any prerequisites such as elevation or user interaction. For updater issues, include the affected release and ZIP filename. Redact credentials and personal details from logs and screenshots.
