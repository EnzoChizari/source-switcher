These players generate 5-second stereo 16-bit PCM WAV files directly at 44.1, 48, 96 and 192 kHz. Playback requires a click and starts at low volume. No AudioContext conversion is involved.



The extension's own test page can read the Gecko API directly. For complete Follow this tab testing, serve this folder on localhost and use the extension button on that ordinary page. The in-page button on an ordinary page may lack extension privilege.
