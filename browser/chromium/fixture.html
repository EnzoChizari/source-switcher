Known PCM playback test

For DAC switching, select Helium as master in Source Switcher. Follow this tab from the extension popup, then start one player. Look for the file header rate in Sources.

These players generate 5-second stereo 16-bit PCM WAV files directly at 44.1, 48, 96 and 192 kHz. Playback requires a click and starts at low volume. No AudioContext conversion is used to create the files.



The extension reads the demo files' WAV headers. Helium may resample the audio before sending it to Windows, so the application stream rate can differ.
